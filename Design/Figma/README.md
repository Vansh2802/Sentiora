# Sentiora Design Reference

This folder contains the approved MVP design system and UI reference.

## Sources of Truth

1. Product Documentation inside `/Docs`
2. Figma Design File
3. Exported Screenshots
4. Exported Assets

## Rules

- Never redesign screens.
- Never invent layouts.
- Never change navigation.
- Never change spacing.
- Never change typography.
- Never change colors.
- Never create new components unless approved.
- Reuse components whenever possible.
- Match the Figma design as closely as possible.

If any design information is missing, stop implementation and ask before making assumptions.

The Figma design is the visual source of truth.
The documents inside `/Docs` are the functional source of truth.
